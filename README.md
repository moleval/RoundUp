# RoundUp

Утилита для AutoCAD на AutoLISP: округление числовых параметров динамических блоков вверх до заданного шага.

## Состав репозитория

| Файл | Назначение |
|---|---|
| `RoundUp.LSP` | Модуль округления параметров блоков, редакция 5. Кодировка CP1251 (Windows-1251), без BOM |
| `ZeroZ.LSP` | Модуль обнуления координаты Z, редакция 1. Кодировка CP1251, без BOM |
| `docs/autolisp-design.md` | Инструкция по проектированию модулей AutoLISP (стандарты кода, таблиц, экспорта) |
| `docs/zero-z-logic.md` | Логика и решения по команде `ОБНУЛИТЬЗЕТ` / `ZEROZ` |

## Команды RoundUp.LSP

| Команда | Что делает |
|---|---|
| `ОКРУГЛИТЬБЛОК` / `ROUNDDBLOCK` | Округляет числовые параметры выбранных динамических блоков вверх до кратного шага |
| `КРАТНОБЛОК` / `KRATNOBLOCK` | Строгое кратное: даже уже кратное значение увеличивается на один шаг |
| `ТЕСТОКРУГЛ` / `ROUNDUPTEST` | Самопроверка функции округления, вывод таблицей в командную строку |

Обе основные команды принимают набор блоков (или работают с предварительно выбранными — implied selection) и запрашивают шаг округления; шаг можно вводить с запятой или точкой в качестве десятичного разделителя. По умолчанию шаг — 1.0.

Отчёты выводятся в командную строку таблицей: всего блоков, динамических/нединамических, найдено параметров, изменено, без изменений, нечисловых значений, ошибок, непринятых блоком значений. Изменения выполняются в рамках одной операции `UNDO`.

## Команды ZeroZ.LSP

| Команда | Что делает |
|---|---|
| `ОБНУЛИТЬЗЕТ` / `ZEROZ` | Приводит объекты модели и всех листов в плоскость Z = 0 |
| `ОБНУЛИТЬЗЕТТЕСТ` / `ZEROZTEST` | Самопроверка: создаёт тестовые объекты, проверяет результат, удаляет их |

Обрабатываются точки вставки, вершины и определяющие точки; внутрь определений блоков команда
не заходит — у вставки меняется только её точка вставки. Размеры, штриховки и таблицы сдвигаются
целиком через ActiveX, поэтому ассоциативность и атрибуты сохраняются. Объекты на заблокированных
слоях и объекты с наклонным вектором выдавливания пропускаются и попадают в отчёт. Все изменения
объединяются в одну операцию `UNDO`, системные переменные не меняются.

Подробности и тест-кейсы: `docs/zero-z-logic.md`.

## Установка

1. Скачать `RoundUp.LSP` и `ZeroZ.LSP` (кнопка **Raw** → «Сохранить как», либо `git clone`).
2. В AutoCAD: `APPLOAD` → выбрать файлы → **Загрузить**.
   Либо перетащить файлы в окно AutoCAD.
3. Для автозагрузки добавить файл в «Пакет автозагрузки» (`Startup Suite`) в диалоге `APPLOAD`.

При загрузке модуль печатает строку с редакцией и таблицу команд.

## Требования

- AutoCAD с поддержкой Visual LISP (ActiveX, `vl-load-com`) — 2000 и новее.
- Русская локаль AutoCAD: параметры блоков ищутся по именам вроде `ШИРИНА`, `ВЫСОТА`, `ДЛИНА`, а также по английским `WIDTH`, `HEIGHT`, `LENGTH`.
- Файл должен оставаться в кодировке CP1251, иначе кириллица в подсказках отобразится некорректно.

## Формат хранения

Исходник получен под именем `RoundUp.pdf`, но по содержимому это текст AutoLISP в CP1251 (шапка `;;; RoundUp.LSP`). В репозитории файл сохранён под правильным именем и расширением.

`.gitattributes` фиксирует для `*.lsp` кодировку Windows-1251 и переводы строк CRLF — так git не будет ломать кириллицу и окончания строк при клонировании на Windows.

## Разработка

При доработке модуля соблюдайте `docs/autolisp-design.md`, в частности:

- отступ 2 пробела, имена функций ASCII, пользовательские тексты — по-русски;
- файлы Lisp — только CP1251 без BOM;
- при любом изменении модуля номер редакции увеличивается, обновляются шапка файла и строка загрузки;
- отчёты в командной строке — табличные, с выравниванием по содержимому;
- все изменения системных переменных — через сохранение и восстановление, в том числе при ошибке и отмене.
